# 기록 조회와 설정 화면 후속 수정

- 기록 탭의 작성/조회 두 진입 카드는 유지했다. 조회 안쪽의 유형별 건수 카드를 제거하고 기존 최근 7일/30일/90일/전체 선택과 캘린더를 유지했다.
- 같은 기록 날짜 안에서는 최초 저장 시각(savedAt, 없으면 createdAt) 내림차순이며 수정 시각으로 순서를 바꾸지 않는다.
- 본문 3줄 미리보기에서 누르면 저장된 본문 전체가 펼쳐진다. 질문 기록은 작성 답변을 별도로 열 수 있고, 기록 상세 경로를 유지해 수정/삭제 기능도 접근 가능하다.
- 직접 기록한 항목에만 연필과 '직접 남긴 기록'을 표시한다. 작성 방식이 불분명한 이관 기록은 직접 작성으로 오표시하지 않는다.
- 새 요약을 만들 때 이미 알려진 선택지 문장과 불확실성 문장만 존댓말로 변환한다. 답변 원문, 자유 입력, 추가 설명, 기존 저장 본문은 일괄 수정하지 않는다. 이전 말투의 수동 편집 초안도 변경 없는 답변에서 충돌 없이 유지한다.
- 설정의 입력한 상황 수정, 문답 연결 상태, 개인 참고자료 영역을 제거하고 첨부 이미지의 정보 아이콘과 회색 안내사항 영역을 적용했다. 데이터 보관 설명과 알림 목록은 유지했다.
- 분기 질문의 안내 보기 버튼 및 선택 설명 상자를 제거했다. 질문 이해용 간단한 문장과 미확인/모름 답변 뒤의 상세 GuidanceCard, 체크리스트 상세 안내는 유지했다. 분기 판단 및 저장 로직은 변경하지 않았다.
- 시간 선택 Modal은 자체 slide 전환 대신 고정 배경의 opacity와 선택창 translateY를 별도로 구동한다. 닫기/완료도 반대로 전환한 뒤 처리하며 Reduce Motion을 따른다. 휠만 스크롤되고 화면 높이에 맞춰 표시 행 수를 조정한다.

검증: 타입 검사와 Expo lint 통과. 기존 및 신규 회귀 총 97개 통과. iOS/Android Hermes 및 웹 번들 생성 성공. 390px 웹에서 설정/기록 조회 확인. 실제 기기의 휠 제스처와 iOS 전환 체감은 기기 확인이 필요하다.
