# 초기 안내 UX·3탭·준비 조작 변경 · 2026-11-02

- 실제 라우팅은 `src/app/(tabs)/`의 홈(`/home`)·기록(`/record`)·설정(`/settings`)이다. 문답·확인·수정은 기존 `/records` 스택 화면으로 열어 탭을 숨긴다. 저장 성공 후 `/record?day=…&featured=…`로 복귀한다. 탭은 화면을 유지하며 기록의 선택 월/날짜를 보존한다.
- 최초 단계 파악은 신청→방문조사→결과의 질문형 분기 유지. 이후 단계 변경은 현재 단계 표시→4개 상황 직접 선택이다. 이미 저장한 상황·준비 답변은 재사용하며 미응답 항목만 초기 안내에서 확인한다. 설정의 ‘입력한 상황 수정’에서 관련 상황만 바꾼다.
- 선택 행의 원형 글리프 제거, 배경/테두리와 접근성 선택 상태 유지. 질문 묶음은 상단 여백을 둔 스크롤 영역, 주요 행동은 아래쪽이다. 같은 화면의 질문 변경에 80ms 퇴장+120ms 등장, 동작 줄이기 시 생략. 동기적 쓰기 잠금과 전환 중 터치 차단으로 중복 진행을 방지한다.
- 단계별 기록 용도/기록 탭 안내를 끝에 한 번 표시한다. `recordIntroduced`는 초기 안내/준비 완료와 분리하며 이전 데이터에 없는 경우 안내만 추가로 보여준다. 기존 완료한 준비 안내 전체를 반복하지 않는다. 2단계 일정 확인→기록 안내 유지.
- 홈은 준비 중심이다. 1·3·4단계 내 준비 카드, 2단계 D-Day/방문 일정/방문 준비. 상단 제품 설정 아이콘·홈의 기록 동작·세부 상황 변경 버튼 제거.
- 준비 상세의 내 메모 입력만 제거했다. 상태 저장은 `setEntry({status})`로 기존 note를 건드리지 않는다. 더보기 상태 메뉴 대신 준비/제출/확인·완료 취소·해당 없음·복원 행동을 제공한다. 모름과 명시적인 미준비는 계속 구분한다. 기존 공식 링크는 중복 URL을 제외해 가로 줄바꿈 영역으로 표시한다.
- 필수 준비가 모두 완료/해당 없음이면 실제 절차 완료를 한 번 묻는다. 선택 항목은 막지 않고 미확인 필수 항목은 완료로 세지 않는다. `transitionOffered[scope]`를 먼저 저장해 닫기/아직이에요/재접속 때 반복하지 않는다. 수동 단계 변경은 별개이며 4단계에는 다음 단계가 없다.
- 저장 키/기존 단계 ID/일지·초안·일정·준비 상태·메모는 유지한다. 새 선택 필드는 선택적 속성으로 읽어 구버전 데이터에 파괴적 마이그레이션을 하지 않는다. 첫 실행 테스트는 기존 메모리 저장소 격리를 재사용한다.
- 변경 파일: `src/app/_layout.tsx`, `src/app/(tabs)/{_layout,home,record,settings}.tsx`, `src/app/{guide,situation}.tsx`, `src/components/{selection-row,question-scroll}.tsx`, `src/features/{home/home-screen,start/stage-screen,preparation/{intro-screen,intro-flow,questions-screen,detail-screen,checklist,model,provider,status},records/{records-screen,record-calendar}}.tsx/ts`, `tests/tabs-preparation.test.cjs`.

검증: 변경 관련 로직 13개 통과(분기/진행 복원/데이터 보존/상태/완료 계산). 웹에서 기록 안내→홈, 3탭, 캘린더 월 유지, 완료 단계 직접 복귀, 탭 선택 접근성 확인. 실기기 미감·터치·애니메이션·동작 줄이기·글자 확대·시스템 제스처는 미검증. 실제 AI·음성·서버 연결 상태는 변경하지 않았다.

최종 검사: `npx tsc --noEmit`, `npm run lint` 통과. iOS 실제 번들 생성 성공(`.expo/tabs-preparation-final`, 1,250 모듈). 최초 검사에서 발견된 SDK 58 탭 API/React 훅 오류를 수정한 뒤 해당 검사를 재실행했다. 관련 로직 검사 13개 통과. CLI open.js SHA256은 작업 전후 `F63DA59BF7C928CEB8A44F3E250BBDFAFC046A287900C1D1A9B867A6160F4180`로 동일하며 의존성 재설치는 하지 않았다.

추가 실행 확인: 웹 390px에서 최초 질문→2단계 일정 확인→기록 소개→홈, 직접 3단계 변경→순차 안내→내 준비, 완료한 단계 복귀, 준비 상태 저장·완료 취소, 필수 완료 후 실제 절차 확인 제안/아직이에요, 테스트 종료 후 기존 상태 복원. 선택 캘린더 월은 탭 이동 시 유지됐다. 저장 성공 후 기록 탭으로 이동하는 코드는 실제 번들에 포함됐으나 이번 검증에서는 새 일지를 확정하지 않았으므로 휴대폰에서 해당 이동을 확인해야 한다. 실기기 확대·감각·애니메이션은 미검증이다.
