# 기록과 설정 화면 밀도 및 첫 진입 안내 개선

## 변경 파일

- `src/features/records/records-browser.tsx`: 기록 탭의 진입 카드를 가로 배치로 변경. 아이콘/제목/설명/화살표를 한 행 안에 정렬하고 고정 높이 없이 콘텐츠에 맞게 늘어나요. 목록 카드는 상하 패딩16, 내부 간격8, 카드 간 여백12를 사용해요. 화살표의 별도 줄을 없애 오른쪽 중앙으로 옮기고 날짜 그룹 위 간격을20에서12로 줄였어요. 보고서 진입도 짧은 가로형 카드로 정리했어요.
- `src/app/(tabs)/settings.tsx`: 전체 항목 간격20→12, 메뉴 최소 높이56와 상하 패딩14 적용. 개발자 구분선과 버전 위의 중복 여백 축소.
- `src/features/notifications/provider.tsx`: 알림 항목을 하나의 흰색 그룹에 묶고 행 상하 여백12→4로 축소. 제목 영역과 스위치 영역을 분리하고, 두 스위치 모두 오른쪽의 폭64/최소 높이48 영역 중앙에 정렬했어요. 스위치 자체의 축소와 여백을 막아 제목 줄바꿈에 따라 밀리지 않게 했어요. 기존 알림 동작은 유지.
- `src/features/reset/settings-reset.tsx`: 초기화 버튼과 설명을 간격6인 하나의 그룹으로 정리. 삭제 확인과 처리 범위는 유지.
- `src/app/(tabs)/_layout.tsx`: 말풍선을 탭바 위의 절대 위치로 표시하고 흰색 배경은 실제 탭 영역에만 적용. 안내가 보이는 동안 투명한 전체 터치 영역이 첫 터치를 소비해요. 첫 터치는 말풍선만 닫고, 두 번째 터치부터 카드/탭이 실행돼요. 기존10초 자동 해제와 일회성 표시 조건은 유지.
- `tests/ui-density.test.cjs`: 첫 터치 영역, 해제 후 탐색, 탭바 높이 불변 회귀 검사.

글자 크기, 색상, 카드 테두리, 원본/요약 미리보기 정책, 데이터 저장, AI 호출과 인증 로직은 변경하지 않았어요. 긴 미리보기는 기존 최대2줄 범위에서 높이가 자연스럽게 늘어나며, 전체 내용은 상세에서 확인해요.

## 실제 확인

- 웹390px: 기록 탭, 기록 목록, 설정 화면과 첫 진입 말풍선. 실제 화면은 이 폴더의01~04이미지예요.
- 웹320px: 기록 탭과 목록의 줄바꿈 및 카드 자동 높이.05~06이미지예요.
- 첫 실행 체험에서 말풍선이 보일 때 단계 변경 위치를 처음 누른 후 URL은 `/home`, 말풍선은 사라졌어요. 두 번째 단계 변경 클릭 후에는 `/stage`로 이동했어요.
- 처음 시도한 responder 감지만으로는 웹의 버튼 실행을 차단하지 못해 투명한 터치 영역으로 보완했고, 위 절차로 다시 확인했어요.
- 체험 종료 후 원래 단계/일정/체크리스트로 돌아왔고, 최근30일 가상 기록32건도 그대로 확인했어요. 실제 자료나 접근 코드는 사용하지 않았어요.
- iOS/Android 실기기에서의 글자 확대와 터치 동작은 직접 확인하지 못했어요. 지원되는 공통 React Native 구성으로 구현했지만 웹 확인을 실기기 완료로 대신하지 않아요.
- 별도 테스트용8094 서버만 종료했으며 기존 휴대폰용 서버는 건드리지 않았어요.
