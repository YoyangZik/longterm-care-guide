# AI 기능 구현 검증 (2026-11-04)

실제 개인정보와 실제 Claude API 키는 테스트에 사용하지 않았다. 자동 테스트의 기기 저장소와 AI, 네이티브 모듈은 격리된 메모리 어댑터로 대체했다. 기존 사용자 저장 자료를 변경하는 테스트는 실행하지 않았다.

## 통과한 검증

- `npx expo lint`: 오류와 경고 없음.
- `npx tsc --noEmit`: 통과.
- `node --test tests/*.test.cjs workers/test/*.test.mjs`: 기존 121개와 AI 14개, 총 135개 대상. 기존 설문, 개인화, 기록, 필터, 캘린더, 저장 및 초기화 동작을 포함한다.
- `npx --yes wrangler@4 deploy --dry-run --config workers/wrangler.jsonc --outdir .tmp/worker-bundle`: 번들과 SQLite Durable Object 설정 통과. 실제 계정에 배포하지 않았다.
- 웹 앱의 보고서 화면 로드, 서버 미설정 안내와 생성 버튼 비활성 상태, Cloudflare와 Anthropic Claude 전송 안내, 동의하지 않음을 선택했을 때 동의 없이 안내가 닫히는 것을 직접 확인했다. 기존 기록 본문은 열지 않았다.

자동 테스트는 다음 행동을 실제 비동기 저장과 요청 흐름으로 검증한다.

1. 직접 작성과 질문 작성의 원본이 AI보다 먼저 저장된다. AI 실패 후에도 원본이 남으며 같은 실패를 자동 재시도하지 않는다.
2. 동의 전 요청 수는 0이다. 동의해도 기존 기록이 일괄 전송되지 않는다.
3. 지연 응답 중 수정 시 이전 결과를 저장하지 않고 수정된 내용의 요약을 한 번 요청한다. 삭제한 기록은 다시 생성되지 않는다. 중복 클릭도 요청을 늘리지 않는다.
4. 동의 철회 뒤 응답은 저장하지 않는다. 재시작 시 남은 pending 상태는 재시도 가능한 실패 상태로 전환한다.
5. 7일, 30일, 90일의 시작과 종료일을 모두 포함하고 초안, 범위 밖 기록과 미래 기록을 제외한다. 월 경계와 윤일 계산은 기존 로컬 날짜 함수를 사용한다.
6. 보고서는 원문을 전송하고 생성 시 근거 전체를 저장한다. 다시 읽기와 HTML 생성에는 AI 재호출이 없다. 추가, 수정과 삭제는 갱신 필요로 판별된다.
7. 기록 없음과 96KB 초과는 API 요청 전 차단된다. 가짜 ID, 중복 근거, 단일 기록을 반복으로 표시한 응답과 누락된 근거는 거부한다.
8. iOS와 Android PDF 어댑터에서 공유, 인쇄와 저장 호출, 비동기 파일 복사 완료 후 공유 및 캐시 삭제 순서, AI 재호출이 없음을 모의 네이티브 API로 확인했다. HTML의 사용자 입력과 AI 텍스트 이스케이프를 검사했다.
9. 서버 설정 없음, 미인증, 잘못된 접근 코드, 허용되지 않은 웹 원점, 실제 스트림 크기 초과와 잘못된 유형/기간을 거부한다. Durable Object 모의 저장소에서 동시 요청 제한을 검사했다. API 키와 upstream 오류 본문이 앱 오류에 포함되지 않는다.

## CPU 로컬 측정

Node v26.13.0에서 가상 원문 300건, 요청 95,341바이트, 워밍업 후 200회 실행했다. 실제 Worker 함수를 통과하되 Claude 응답과 Durable Object 연결은 모의로 대체했다.

- 평균 프로세스 CPU: 약 1.10ms/회
- 벽시계 중앙값: 약 1.07ms
- 벽시계 p95: 약 1.64ms

이는 Windows의 Node 로컬 측정이며 Cloudflare 무료 플랜 CPU 10ms 준수를 입증하지 않는다. 실제 최대 크기 입력과 응답에서 Cloudflare Metrics의 CPU와 1102 오류를 배포 후 확인해야 한다. 측정 스크립트는 `workers/scripts/benchmark.mjs`다.

## 직접 검증하지 못한 범위

- Cloudflare 실제 배포, Secret 등록, 실제 Durable Object 계수기와 CPU 메트릭.
- 실제 Claude 모델에서 한국어 결과의 사실성, 원문 내 지시문 공격에 대한 의미상 내성, 모델별 출력 길이와 응답 품질.
- iOS/Android 실제 네이티브 PDF 생성과 공유, AirPrint/Android 인쇄 서비스, OS 파일 저장 선택기.
- 실제 생성 PDF의 한글 글리프, 긴 문장과 여러 페이지에서 제목 및 본문 분리 여부에 대한 시각 검수.

위 미검증 항목은 배포 안내의 가상 자료 체크리스트로 확인해야 한다. 네이티브 API 모의 테스트를 실제 기기 검증으로 간주하지 않는다.
