# 안내 문구 검토 · 2026-11-03

검토 범위: 준비 체크리스트 전체 분기, 설문 질문·도움말·안내, 단계 설명, 방문 일정, 기록 작성·확인·설정의 서비스 설명. 법률 자문이나 개별 신청 자격 판정이 아니라 현재 앱 문구와 공식 자료의 대조다.

## 확인한 내용

- 신청 자격: 연령·노인성 질병 요건과 가입자·피부양자·의료급여수급권자 요건을 함께 확인해야 한다. 신청 자격과 등급 인정은 구분된다.
- 신청 방법: 방문·우편·팩스·인터넷 등과 온라인 제한, 갱신의 신분 확인 후 유선 신청 안내는 공단 자료와 일치한다.
- 서류: 일반 진단서와 장기요양 의사소견서는 구분된다. 65세 미만 신청자가 신청 시 소견서를 내지 않으면 노인성 질병 증빙이 필요하다.
- 갱신: 유효기간 종료 90일 전부터 30일 전까지라는 안내를 유지했다.
- 방문조사: 사전 일정 안내, 담당자와 협의, 평소 실제 도움을 기록하는 안내를 유지했다. 개인 일지는 공식 조사나 자동 제출 자료가 아니다.
- 판정 기간: 신청서 제출일부터 원칙적으로 30일, 부득이한 경우 30일 범위 연장. 방문일부터 결과 수령일까지 30일을 보장한다는 의미가 아니다.
- 결과 이후: 인정서·개인별장기요양이용계획서 확인, 급여 종류·비용·기관 상담 안내를 유지했다.
- 심사청구: 처분을 안 날부터 90일, 처분일부터 180일 제한 및 정당한 사유 예외 안내를 확인했다. 새 신청·등급변경과 구분한다.
- 앱 기능 설명: 기기 내 저장, 자동 제출·진단·등급 예측 없음, 현재 고정 문답·모의 정리라는 설명은 구현과 대조했다.

## 보강한 내용

- 인정 기준의 6개월은 신청 전 6개월 대기 의무가 아님을 설명했다.
- 소견서 제출 가능 시점, 개별 제출기한 준수와 제출 대상자 미제출 시 판정 불가를 추가했다.
- 발급의뢰서와 실제 소견서의 차이, 의뢰서 없이 발급받을 때의 비용과 공단 확인 필요를 추가했다.
- 안내받은 경우 치매진단 보완서류를 준비하도록 설명했다.
- 방문 시 신분증 제시와 우편·팩스 시 사본 제출을 구분했다.
- 등급을 받은 경우에도 처분 내용에 이의가 있을 수 있음을 명시했다.
