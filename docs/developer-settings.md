# 설정 및 개발자 설정 정리 (2026-11-04)

## 최종 메뉴

설정 탭의 기존 알림 설정, 앱 안내사항과 앱 데이터 초기화는 유지했다. 이 저장소에는 별도의 데이터 내보내기 메뉴가 없으므로 이번 작업에서 새로 구현하지 않았다. 기존 순서를 유지하고 하단 구분선 아래에 개발자 설정을 배치했다.

- 설정
  - 기록 알림 및 방문조사 일정 알림: 기존 NotificationSettings
  - 앱 안내사항: 기존 경로
  - 앱 데이터 초기화: 기존 SettingsReset
  - 개발자 설정
    - 첫 실행 흐름 보기: 기존 개발 빌드의 `useFirstRunTest().begin` 재사용
    - AI 이용 설정
    - 기능 테스트용 가상 자료: 개발 빌드에서 기존 90일 기록 추가 기능 재사용

첫 실행 흐름은 기존처럼 개발 빌드에서만 제공한다. AI 이용 설정은 배포 빌드에서도 개발자 설정 아래에서 접근할 수 있다. 첫 실행 테스트 도중에는 실제 설정을 변경하지 않도록 개발자 설정 진입과 새 설정 경로를 막는다. 테스트 종료는 기존 하단 버튼을 재사용한다.

## AI 설정 화면 상태

입력값이 아니라 SecureStore(웹은 기존 메모리 어댑터)에서 코드 존재 여부를 읽는다. 기존 저장 키와 동의 버전, 코드의 서버 인증 과정은 유지한다. 화면을 열거나 설정이 바뀌면 상태를 다시 읽는다.

| 상태 | 표시 및 동작 |
| --- | --- |
| 동의 전 | 외부 AI 전송 안내와 동의 버튼, 코드 입력창 없음 |
| 동의 완료, 저장 코드 없음 | 코드 입력창과 등록 버튼, 동의 철회 버튼 |
| 동의 완료, 코드 저장됨 | 준비 완료 안내, 접근 코드 삭제, 동의 철회하기만 표시 |
| 동의 철회 후 | 재동의 안내, 코드 입력창 없음, 저장 코드는 유지 |
| 코드 삭제 후 | 동의 유지, 코드 입력창 재표시 |
| 저장 코드를 유지한 채 재동의 | 코드 재등록이나 추가 서버 호출 없이 관리 화면 표시 |

서버 미설정 경고는 유지한다. 미설정 시에는 준비 완료라고 표시하지 않는다. 등록 성공과 오류 확인창, 64자리 붙여넣기, 키보드 완료/빈 공간/스크롤 처리도 유지한다.

접근 코드 삭제는 `deleteAccessCode()`로 해당 코드만 지운다. 동의 철회는 기존 `consent(false)`를 사용하며 새 AI 요청과 철회 후 도착한 결과의 저장은 기존 동의 검사로 차단한다. 이미 외부로 전송을 시작한 요청은 회수할 수 없다. 원본, 요약과 저장된 보고서는 지우지 않는다.

기록 상세에서는 원문과 AI 한 줄 요약 및 기존 재시도 버튼만 제공한다. 설정 카드와 접근 코드 UI, 설정 화면으로의 강제 이동은 없다. 보고서 화면에서도 설정 관리 UI를 제거했다. 미준비 상태라면 간단한 안내만 표시하고, 기존 보고서 열기와 PDF 출력은 계속 사용할 수 있다.

## 검증

- 실제 AI 설정 컴포넌트를 격리된 React 훅/네이티브 API 어댑터로 렌더링해 위 상태들을 확인했다. 입력창에 64자만 입력했을 때는 등록 완료로 바뀌지 않고, 가상 서버 인증과 실제 테스트 저장 어댑터 쓰기가 완료되어야 관리 버튼 두 개가 표시되는지 확인했다.
- 접근 코드 삭제 시 동의 유지, 철회 시 코드 유지와 요청 0회, 재동의 시 저장 코드 재사용을 검사했다. 원본 기록, 보고서와 알림 설정의 기존 저장값이 그대로인지 비교했다.
- 첫 실행 테스트 저장소의 기존 회귀 테스트에 AI 동의, AI 보고서와 알림 설정을 포함했다. 테스트 세션의 온보딩과 설문 상태를 변경하고 재시작해도 실제 저장소의 모든 바이트가 유지되는지 확인했다. 첫 실행 기능 자체를 새로 구현하지 않았다.
- 기존 AI 요약과 보고서, 기간 경계, 원본 저장, 수정/삭제 응답 보호 및 PDF 어댑터 회귀 테스트를 함께 실행했다. PDF 어댑터와 UI 테스트는 모의 네이티브 API 기반이며 실제 iOS/Android 시각 검증을 뜻하지 않는다.
- 이번 작업에서는 사용자 PC의 개발 서버를 새로 띄우거나 기존 사용자 데이터와 접근 코드를 변경하지 않았다. 실제 휴대폰 화면 및 네이티브 SecureStore 동작은 추가 확인이 필요하다.

## 배포

이번 설정 메뉴 정리로는 Workers 코드와 인증 계약을 바꾸지 않았다. **이번 변경 때문에 Cloudflare Workers를 재배포할 필요는 없다.** 앱을 새로고침하거나 앱 업데이트로 반영한다. 이전 요약 지침 변경의 미배포 여부와는 별개다.
