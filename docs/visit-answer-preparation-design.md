# 예상 질문에 답해보기 설계안

> 2026-11-04 후속 지시로 변경: 현재 구현은 ‘방문조사 질문 살펴보기’이다. 답변 입력, 답변 분기, 답변 정리본과 PDF는 이번 기능에서 제외한다. 질문마다 대답을 떠올리는 안내와 다음 버튼을 제공하고 진행 위치와 열람 완료만 저장한다. 아래의 기존 설계 중 이 변경과 충돌하는 요구는 적용하지 않는다. 관련 돌봄기록은 선택적으로 열람하며 원본이나 체크리스트 상태는 자동 변경하지 않는다.

> 추가 변경: 질문 하단의 ‘이전 질문’과 관련 돌봄기록 열람을 제거했다. 상단 뒤로가기는 홈으로 복귀하고 진행 위치는 유지한다. 체크리스트의 별도 항목은 ‘방문조사 후 확인할 내용’으로 표시한다.

작성일: 2026-11-04
상태: 구현 전 설계안. 아래 순서는 앱에서 대화가 자연스럽게 이어지도록 구성한 순서이며 실제 조사자의 고정 질문 순서나 질문 빈도를 뜻하지 않는다.

## 목적과 문체

- 보호자가 평소 상태와 실제로 제공한 도움을 떠올리고 설명할 수 있도록 돕는다.
- 공식 조사표의 영역을 참고하되 실제 문항을 그대로 재현하거나 적중률을 목표로 하지 않는다.
- 넓게 묻는 시작 질문과 구체적인 생활 장면 질문을 섞는다. 추상적인 표현으로 답변 기준까지 모호하게 만들지는 않는다.
- 어려움이 있다고 전제하지 않는다. 가능한 일과 도움이 필요한 일을 모두 표현할 수 있게 한다.
- 점수, 모범답안, 등급 예측, 답변을 유리하게 만드는 표현을 제공하지 않는다.
- 문장과 버튼에서 가운데점을 쓰지 않는다.

## 홈과 첫 안내

방문조사 대기 단계의 홈에서 체크리스트 제목 옆에 느낌표 아이콘을 포함한 독립 진입 버튼을 둔다. 큰 글씨나 좁은 화면에서는 버튼이 다음 줄로 내려가도록 하고 최소 터치 영역을 유지한다. 팝업은 사용하지 않는다.

| 저장 상태 | 진입 문구 | 이동 위치 |
| --- | --- | --- |
| 시작 전 | 예상 질문에 답해보기 | 첫 안내 |
| 작성 중 | 이어서 답해보기 | 저장된 마지막 진행 위치 |
| 완료 후 | 정리한 답변 보기 | 답변 정리본 |

첫 안내 제목: 평소 돌봄 상황을 정리해 볼까요?

설명: 방문조사 때 설명하기 쉽도록, 직접 보거나 도와드린 내용을 정리해요. 모르는 내용은 넘어가도 괜찮아요.

보조 안내: 공식 조사표를 참고한 준비용 질문이며, 실제 질문은 다를 수 있어요.

대표 버튼: 시작하기

## 대화 순서와 기본 질문 초안

공식 자료에서 확인되는 생활 기능, 인지, 행동, 간호, 지원 환경 등의 영역을 일상적인 대화로 재구성한다. 첫 질문에서 어려움을 선택하지 않았더라도 다른 영역 전체를 생략하지 않는다.

| 순서 | 주제 | 한 화면에 표시할 질문 초안 |
| --- | --- | --- |
| 1 | 생활 이야기 | 요즘 어르신은 하루를 어떻게 보내시나요? |
| 2 | 돌보는 환경 | 평소에는 누가 곁에서 도와드리나요? |
| 3 | 넓게 떠올리기 | 하루 중 누군가의 손길이 필요한 때가 있나요? |
| 4 | 일어나기 | 침대나 의자에서 일어나실 때는 어떠세요? |
| 5 | 이동 | 집 안에서 다른 곳으로 가실 때는 어떻게 이동하세요? |
| 6 | 식사 | 식사를 차려드린 뒤, 드시는 동안에는 어떤 도움이 있나요? |
| 7 | 씻기 | 세수나 양치를 하실 때는 어떠세요? |
| 8 | 목욕 | 몸을 씻거나 목욕하실 때는 어떤 도움이 있나요? |
| 9 | 옷 입기 | 옷을 갈아입으실 때는 어떠세요? |
| 10 | 화장실 | 화장실을 이용하실 때는 어떤 도움이 있나요? |
| 11 | 기억 | 최근 있었던 일이나 해야 할 일을 기억하시는 건 어떠세요? |
| 12 | 의사소통 | 말씀을 주고받거나 뜻을 전하실 때 어려운 점이 있나요? |
| 13 | 행동과 수면 | 밤에 주무시거나 낮에 지내실 때, 곁에서 살펴야 하는 일이 있나요? |
| 14 | 건강 돌봄 | 집에서 받고 계신 치료나 간호가 있나요? |
| 15 | 생활 지원 | 약을 챙기거나 식사를 준비하는 일은 어떻게 하고 계세요? |
| 16 | 마무리 | 방문 때 꼭 전하고 싶은 이야기가 더 있나요? |

1번과 3번은 편하게 떠올리는 용도로 짧은 자유 입력 또는 주제 선택을 제공하며 건너뛸 수 있다. 여기서 선택한 내용은 다른 질문의 답변으로 복사하지 않는다.

## 선택지와 후속 질문

- 생활 동작은 혼자 하는지, 말로 알려주거나 지켜보는지, 일부 동작을 직접 돕는지, 대부분 직접 돕는지를 생활 표현으로 구분한다. 이를 공식 평가 등급과 동일시하지 않는다.
- 혼자 하는 경우에도 보조기구 사용 여부는 별도로 표현할 수 있게 한다. 기구 사용만으로 사람의 도움이 필요하다고 판단하지 않는다.
- 모든 질문에 잘 모르겠어요와 건너뛰기를 제공한다. 모르겠음, 넘어감, 어려움 없음은 서로 다른 상태로 저장한다.
- 도움이나 어려움이 있다고 답하면 어떤 부분을 도와드리는지 한 화면에서 하나씩 이어서 묻는다.
- 상태에 따라 달라요를 선택하면 보통 어떤지와 달라지는 때를 각각 선택적으로 묻는다. 가장 어려웠던 하루만으로 평소 상태를 정하지 않는다.
- 인지나 행동은 관찰한 일, 당시의 도움, 반복되는 양상을 묻되 증상명이나 진단을 추정하지 않는다.
- 치료와 간호는 알고 있는 처치만 선택하거나 직접 적는다. 잘 모르는 의료 정보를 요구하지 않는다.
- 팔과 다리 움직임의 어려움은 이동 등의 후속 질문에서 묻는다. 동작을 시험하거나 관절 범위를 측정하도록 요구하지 않는다.
- 필요하면 기억나는 일을 하나 적을 수 있지만 사례 입력은 필수가 아니다. 날짜가 없는 사례를 날짜가 있는 돌봄기록으로 변환하지 않는다.

## 저장과 수정

- 답변 원문, 선택 값, 모름과 건너뜀 상태, 진행 위치, 완료 여부를 독립적으로 저장한다.
- 선택, 입력, 화면 이동, 뒤로가기와 앱 비활성화에 맞춰 자동 저장한다. 저장 실패 시 성공한 것으로 표시하지 않고 입력을 유지한다.
- 완료 후 각 항목의 수정으로 바로 들어간다. 수정 후에는 정리본으로 돌아가며 전체 문답을 다시 시작하지 않는다.
- 상위 답변 변경으로 후속 질문이 불필요해져도 과거 입력을 조용히 삭제하지 않는다. 현재 정리본에서 제외하고 다시 해당 분기를 선택하면 복원한다.
- 홈으로 돌아오거나 앱을 재실행해도 진행 위치를 복원한다. 기존 내부 ID와 저장 키가 있으면 이름 변경을 이유로 교체하지 않는다.

## 인계문에서 유지할 부가 기능

- 관련 돌봄기록은 사용자가 원할 때만 펼쳐 본다. 열람 여부와 기록 유무는 다음 질문이나 완료의 조건이 아니다.
- 관련성은 저장된 유형과 명시적인 분류 기준으로 연결한다. 기존 유형이 넓게 묶인 경우 정밀하게 일치한다고 표시하지 않는다.
- 기록을 답변에 자동 복사하지 않는다. 기록 수정과 삭제가 답변을 바꾸지 않는다.
- 정리한 답변과 날짜가 있는 실제 기록을 구분한다. 정리본은 답변을 항목별로 배치하고 알려진 선택 문구만 다듬으며 자유 입력을 임의 해석하지 않는다.
- 유형과 기간으로 기록을 모아보고 개별 상세를 확인하는 요구는 유지하되 기존 기록 화면은 이번 명칭과 진입 작업 때문에 개편하지 않는다.
- A4 PDF 열람과 출력 요구를 유지한다. 답변과 사례를 구분하고 휴대폰 정리본과 같은 선택 범위를 사용한다. 출력 범위와 레이아웃의 세부안은 별도 검토 대상으로 남긴다.
- FAQ는 인계문상의 별도 기능이다. 이번 문답을 구현하면서 홈 메뉴나 FAQ를 임의로 추가하지 않는다.
- 문답 완료가 체크리스트 완료나 돌봄기록 생성으로 이어지지 않는다.

## 확인할 항목

- 세 상태의 홈 문구와 연결 화면, 중단 위치 복원, 개별 수정 후 정리본 복귀
- 뒤로가기와 홈 복귀 시 저장, 저장 실패 후 입력 보존
- 기록이 전혀 없는 상태에서 완료, 기록 삭제 후 기존 답변 보존
- 상위 분기 변경 후 제외와 복원, 모름과 건너뜀의 구분
- 큰 글씨에서 질문과 선택지 전체 노출, 버튼 줄바꿈, 최소 터치 영역
- 실제 기기에서 종료와 재실행, 키보드, 화면 이동 확인
