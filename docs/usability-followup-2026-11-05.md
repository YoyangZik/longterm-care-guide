# 실사용 개선 2~4단계 수정 및 검증

1단계 안정화는 유지하고 반복 구현하지 않았다. 실제 AI API 호출과 배포는 하지 않았다.

## 2단계: 기록과 최초 설문 복귀

- `situation-screen.tsx`: 두 기록 방식 모두 원본 저장 성공 후 `/records-review`로 이동한다. 저장 실패는 입력을 유지하며 이동하지 않는다.
- `save-followup.ts`, 알림 Provider, `review-screen.tsx`: 알림 갱신 실패는 원본 저장 실패와 구분한다. 목록에서 저장 성공과 알림 확인 필요를 안내한다.
- `records-browser.tsx`: 방금 저장한 기록은 목록 상단에서 한 번만 강조하며 자동으로 상세 화면을 열지 않는다. 과거 기록을 저장했을 때도 기본 30일 필터에 숨지 않도록 최초 조회 기간을 정한다. 캘린더는 유지한다.
- `initial-survey-return.ts`, 준비 Provider, `intro-screen.tsx`, `guide.tsx`, `visit.tsx`, `home-screen.tsx`: 사용자가 승인한 규칙에 따라 최초 설정 후 처음 홈에 도착한 세션에서 마지막 질문으로 복귀할 수 있다. 홈의 복귀 버튼과 기존 뒤로가기 보호 흐름을 사용한다. 홈을 떠나면 복귀 기회는 해제하며 재실행 후 자동 재생하지 않는다. 복귀 시 답변과 준비 항목은 보존하고 해당 설문의 진행 위치와 완료 표시만 다시 연다. 기존 단계 변경 경로는 유지한다.

## 3단계: 앱과 PDF 표시

- `report-presentation.ts`: 기존 본문의 명시적 문단 경계를 앱과 PDF에서 동일하게 해석한다. 저장된 보고서 본문을 다시 쓰거나 문장을 삭제하지 않는다.
- `report-content.tsx`: 문단별 여백과 줄간격을 적용한다. 근거 원문에는 참조 번호, 날짜, 유형을 표시하고 내부 ID 표시를 제거한다.
- `report-html.ts`: 근거 목록을 한 번만 출력하고 본문별 연결은 참조 번호 또는 전체 기록 범위로 표시한다. 근거 원문은 모두 유지하되 본문보다 낮은 서체 크기와 시각적 강조를 사용한다. HTML 이스케이프와 원문 앵커를 유지한다.
- `workers/src/protocol.js`: 새 생성 결과에 의미 단위의 빈 줄 문단과 항목 간 사례 반복 억제를 요청한다. 두 본문을 통합하지 않으며 근거 검증은 변경하지 않는다. 서버 프롬프트 변경은 Workers 재배포 후 실제 서비스에 반영된다.
- 가상 기록 90건의 PDF 16쪽을 Edge로 생성한 뒤 Poppler로 전체 렌더링했다. 전체 축소 보기와 첫 장·마지막 장 확대 보기에서 문단, 본문/부록 계층, 한글, 페이지 경계를 확인했다. iOS/Android의 실제 인쇄 엔진 검증과 같지는 않다.

## 4단계: 실제 생성 상태

- `ai-client.ts`: 기록 확인, 실제 요청 전송/응답 대기, 응답 근거 검증/저장, 저장 완료의 콜백을 제공한다.
- `report-progress-state.ts`, `report-progress.tsx`, `reports-screen.tsx`: 위 콜백으로만 단계를 전환한다. AI 내부 작성 진행률은 알 수 없다고 안내한다. 임의 퍼센트를 표시하지 않는다. 실패 시 완료 표시를 하지 않고 기존 오류/수동 재시도 흐름을 유지한다.

## 검증

- TypeScript: `npx.cmd tsc --noEmit` 통과.
- Lint: `npx.cmd expo lint` 통과.
- 전체 회귀: `node --test tests/*.test.cjs workers/test/*.test.mjs` 180개 통과. 공유 폴더의 다른 작업 변경까지 포함한 해당 시점 결과다.
- 추가 회귀는 두 기록 방식의 저장 실패/알림 실패/목록 이동, 과거 기록 강조, 마지막 질문 복원과 홈 이탈 시 해제, 분기 변경 후 다음 질문, 앱/PDF 문단·참조 일치와 데이터 불변, 실제 네트워크·저장 완료 전후 진행 상태, 오류 시 미완료를 확인한다.
- 관련 테스트: `tests/usability-followup.test.cjs`, `tests/helpers/ui-fixture.cjs`, `tests/ai-records.test.cjs`.

## 남은 검증 및 사용자 결정

- iOS/Android 실기기 재실행, 뒤로가기·제스처, 알림, PDF 공유·인쇄는 미검증이다.
- 실제 Claude 생성 품질·긴 기간 응답 속도와 ExpoAsset 오류의 기기 재현은 확인하지 않았다. 실제 AI 호출은 별도 승인이 필요하다.
- 보고서 본문 두 항목 통합, PDF 제목·파일명, 원문 전체 포함 정책, 더미/실제 기록 혼합 정책은 변경하지 않았다.
- 이미 저장된 한 문단 보고서는 의미를 추측해 자동 분할하지 않는다. 기존 문단 경계는 새 표시 방식으로 적용되며, 새 보고서에는 개선한 프롬프트를 사용한다.
- 공유 폴더의 다른 채팅이 알림 정책·페이지 이동·초기화·글자 표시를 동시에 수정했다. 해당 변경은 보존하고 사용자 승인으로 파일 범위 조율 메시지를 전달했다.
