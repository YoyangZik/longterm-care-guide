# UI·문구·뒤로가기 수정 · 2026-11-02

중단된 마지막 요청을 이어서 마무리했다. 이전 tabs-preparation 문서의 상세 상태 행동·문구보다 이 변경이 우선한다.

- 준비 상세: 선형 아이콘과 짧은 제목, 안내 바로 아래 공식 링크·13px 출처/기존 확인일, 하단 항목별 대표 행동. 결과 확인의 처리 기간은 접어서 확인한다. 준비/제출 완료는 버튼을 직접 눌러야 반영된다. 완료 후 다시 변경하기에서 미완료와 모름을 구분하며 기존 해당 없음과 메모를 보존한다.
- 설문: 선택 행을 둥근 그룹과 내부 구분선으로 묶고 선택 시 작은 체크를 표시한다. 질문/답변 간격을 줄이고 항목별 행동 질문과 답변을 사용한다. 준비 중과 미응답을 합치지 않는다.
- 이동: 완료된 안내는 이전 질문으로 돌아가지 않는다. 신청 경험 수정의 두 번째 질문에서 뒤로가면 첫 질문으로 복귀한다. 최초 단계 파악에서 넘어온 미완료 안내는 저장된 직전 단계 질문으로 돌아가며, 홈의 단계 변경은 기존 네 상황 직접 선택을 유지한다.
- 홈: 방문 대기 제목/일정/대표 버튼을 하나의 유연한 그룹으로 배치하고 별도 D-Day 배지를 제거했다. 단계 문구와 두 꺾쇠를 하나의 터치 영역으로 제공한다. 체크리스트 제목과 기존 카드/완료 표시를 유지한다.
- 설정: 제목을 설정으로 통일하고 상황 수정 진입점을 스크롤 안의 메뉴로 정리했다. 달력 옆 오늘 문구만 제거하고 내부 오늘 표시와 기록 달력 48×72 기본 터치 영역을 유지했다.
- 탭: unstable_settings.anchor는 home, Tabs.backBehavior는 initialRoute로 설정했다. SDK 58 공식 Router settings 문서의 deprecated initialRouteName 대체 지침을 확인했다.

검사: 최종 타입 검사와 린트 통과. 관련 회귀 17개 통과(완료 후 이전 이력 차단·분기 변경 보존 2개 추가). 기존 CLI open.js SHA256 F63DA59BF7C928CEB8A44F3E250BBDFAFC046A287900C1D1A9B867A6160F4180 유지. 새 라이브러리·재설치·사용자 데이터 초기화 없음. 번들 생성은 하지 않았다.

실행 검증 한계: 개발 서버를 8082에 시작했으나 브라우저 도구가 localhost/LAN 주소에 연결되지 않아 이번 실제 화면/터치/글자 확대 검증은 완료하지 못했다. Expo에서 1~4단계 완료와 뒤로가기, 분기 변경, 홈→상세→뒤로, 완료/다시 변경, 기록·설정 탭 뒤로가기로 홈 복귀, 작은 화면/큰 글자를 확인해야 한다.
