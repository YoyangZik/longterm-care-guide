## 웹 실행 결과

실제 돌봄 답변을 사용하지 않고 별도 로컬 웹 환경에서 가상 답변으로 확인했다. 기존 기록·초안을 자동 삭제/초기화하지 않았다.

1. 캘린더
   - 확정 일지를 바로 펼치며 초안별 이어쓰기 버튼/작성 중 목록이 없다. 완료 2건과 작성 중 1건이 있는 날짜에서도 확정 2건만 본문으로 표시됨을 확인했다.
   - 새로 저장한 추가 기록이 가장 먼저 나오며 기존 확정 일지가 아래에 남아 있다. 저장 성공 후 대상 날짜가 선택되고 해당 본문 위치로 스크롤한다.
   - 선택은 배경/테두리/밑줄과 접근성 label/state로 구분된다. 웹에서 aria-selected=true를 확인했다.
   - 날짜 터치 영역은 기본 48×72, 글씨는 18을 유지했다. 기록 없는 날짜의 반복 대시, 본문 날짜 제목과 관리용 건수 설명이 없다. 빈 날짜에는 ‘이날 남긴 기록이 없어요.’만 나온다. 과거 날짜 새 작성 버튼은 없다.
2. 초안 접근
   - 홈 ‘작성 중 이야기’ → 별도 목록 → 기존 초안 이어쓰기를 확인했다. 당일 홈 이어쓰기와 전체 작성 중 목록 경로를 유지했다.
   - 긴 가상 답변을 보내지 않고 뒤로 나가도 임시 저장되며, 캘린더에는 이를 작성 중 표시로만 반영한다. 본문은 확정 일지만 유지한다.
   - 초안 삭제는 목록의 더보기/확인 절차로 접근한다. 실제 영구 삭제는 이번 웹 검증에서 실행하지 않았다.
3. 일지 확인
   - 기본 상태에 입력창이 없고 읽기 텍스트로 시작한다.
   - 수정하기 → 입력창 → 수정 내용 반영 → 읽기 텍스트 → 확인하고 저장을 확인했다.
   - 띄어쓰기를 고친 최종 내용과 답변 원문/원문 기반 모의 초안이 별도로 남음을 확인했다.
   - 저장 실패 보존은 자동 검사로 확인했다. 실제 기기의 저장 실패를 강제로 발생시키는 검증은 하지 않았다.
4. 홈
   - 현재 단계와 변경은 보조 정보/더보기다. 방문 D−N, 제목, 오늘 기록 보기 또는 이야기 남기기가 중심이다.
   - 관리용 기록/작성 중 건수와 중복 준비 요약이 없다. 지난 기록·작성 중 이야기·방문 준비 진입점을 유지한다.
5. 방문 일정
   - 달력에서 날짜 선택 후 재입력 없이 저장 가능하다. 날짜 문자열 입력창은 없다.
   - 시간 선택기를 필요할 때 열어 오후 2:02를 선택하고 저장한 뒤 홈 D−8/11월 10일/오후 2:02 반영을 확인했다.
   - 시간 선택기를 열지 않고도 일정 저장이 되며 홈에서 시간 미정으로 표시된다. 일정 미정 선택 경로도 유지한다.
   - 기존 일정 변경을 피하려고 개발용 첫 실행 테스트 안에서 검증했다. 종료 후 원래 일정이 유지됨을 확인했다.
6. 작은 화면과 문답
   - 390×844, 320×568 웹 뷰포트에서 확인했다. 긴 고정 질문을 32/46으로 유지하며 자동 축소하지 않는다.
   - 긴 가상 입력은 입력창 내부에서 스크롤되고 보내기와 겹치지 않는다. 320 너비에서 페이지 가로 넘침이 없음을 확인했다.
   - 키보드로 가용 높이가 줄어드는 상황을 대신해 320×360으로 줄여 검사했다. 입력 초점 후 보내기 하단은 331로 화면 높이 360 안에 있고 입력창과 겹치지 않았다. 질문과 본문은 세로 스크롤로 접근한다.
   - 실제 키보드/시스템 글자 확대를 검증한 것으로 간주하지 않는다.

## 휴대폰 확인 순서

1. 홈에서 단계/일정은 보조로, 주요 행동 하나는 가장 먼저 보이는지 확인한다. 단계·일정 변경은 상단 더보기에 있다.
2. 오늘 이야기 남기기/이어서 이야기하기 → 긴 답변 입력 → 뒤로가기 → 홈의 작성 중 이야기에서 복원을 확인한다.
3. 마무리 후 일지 확인이 읽기 텍스트로 시작하는지, 수정하기에서만 입력창이 나오는지 확인한다. 반영 후 원문과 비교하고 저장한다.
4. 캘린더 선택 상태와 방금 쓴 내용의 우선 표시를 확인한다. 초안 목록은 없어야 하며 빈 날짜에는 안내 한 문장만 보여야 한다.
5. 오늘 내용 추가하기로 별도 내용을 저장한다. 새 내용이 먼저 나오고 이전 내용도 남는지 확인한다.
6. 방문 일정에서 달력만 눌러 날짜를 선택하고 시간 생략/시간 선택/미정을 각각 확인한다. 홈 D-Day와 한국어 날짜·시각이 즉시 바뀌어야 한다.
7. 시스템 글자를 크게 설정한 뒤 작은 화면·키보드·세로/가로 방향에서 문답/편집/달력/시간 선택기의 모든 내용과 버튼에 스크롤로 접근 가능한지 확인한다. 날짜 열은 글자 확대에 따라 넓어지며 좁은 화면에서는 가로로 넘길 수 있다.
