# 최초 설문 후 안내 복원

2026-11-04. 이전 변경에서 설문 마지막 답변과 방문 날짜 저장 후 바로 홈으로 이동하도록 연결하면서 기록 강조 안내까지 제거된 것이 원인이었다.

최초 개인화 저장 완료 후 `개인화 완료 안내 → 돌봄기록 안내 → 홈`으로 연결했다. 질문 중간의 추가 안내를 되살리지 않고, 설문 뒤의 두 안내만 공통 경로로 복원했다. 기존 GuideIcon, QuestionScroll, 제목과 본문 스타일, TaskActions와 Action을 재사용한다.

Preparation의 선택 필드 `completionGuide`에 `personalized`, `records`, `done`을 저장한다. 완료되지 않은 설문에는 안내를 시작하지 않는다. 각 대표 버튼을 눌러 저장에 성공한 뒤에만 다음 화면으로 진행한다. 기존 setup, recordIntroduced, 완료한 intros와 guidance.seen 이력은 재노출 방지에 사용하며 초기화하지 않는다. 단순 단계 변경으로 안내를 새로 만들지 않는다.

중단 후에는 저장된 안내 화면부터 재개하고, 마지막 버튼은 기존 안내 스택을 정리한 뒤 홈으로 이동한다. 기록 작성 경로는 열지 않는다. 완료한 설문의 guide 경로와 안내 경로로 돌아와도 홈으로 연결한다.

테스트 저장소로 네 단계의 최초 진입, 안내별 재시작, 저장 실패 후 재시도, 기존 이력과 데이터 보존을 검사했다. 별도 브라우저 출처에서 실제 화면 순서, 기록 안내 중 재접속, 완료 후 홈 이동과 뒤로가기, 재접속 시 재노출 방지를 확인했다.
